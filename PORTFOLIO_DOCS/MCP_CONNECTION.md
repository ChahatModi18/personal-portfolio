# Model Context Protocol (MCP) Integration — Personal Portfolio Website

> **Document Version:** 1.0.0  
> **Project:** Personal Portfolio Website  

---

## 1. Overview & Pair-Programming Integration

Enables AI agent pair-programmers (such as Antigravity IDE) to query project states, audit links, and update project metadata.

---

## 2. Tool Definitions

- **`sync_portfolio_projects(github_user)`**: Audits public GitHub repos and generates draft project cards.
- **`audit_portfolio_seo()`**: Validates OpenGraph tags, canonical links, and Lighthouse metrics.
