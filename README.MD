## PROJECT DEVELOPMENT WORKFLOW
The portfolio website was developed through a controlled
9-task workflow using Antigravity.

Each task was intentionally separated so that:
1. One task is completed at a time.
2. Antigravity notifies the developer after completion.
3. Antigravity waits for confirmation before proceeding.
4. Required images/PDFs are explicitly requested from the
   portfolio owner.
5. Resume information is treated as factual source material.
6. Project screenshots are supplied by the portfolio owner.
7. No fictional information or assets are generated.
8. Major changes can be reviewed before proceeding.
9. The final project remains easy to maintain and update.

## APPROVAL RULE
No significant resume-based portfolio changes should be applied
without explicit user approval.

If the user says:
"Apply these changes."
Proceed.
If the user says:
"Don't apply yet."
Do not modify the website.
If the request is ambiguous, ask for confirmation.

---

## ROLLBACK RULE
Before major changes:
* Create a Git commit or recoverable snapshot.
* Preserve the previous working version.
* Never recreate the previous version from memory.

If rollback is requested:

* Restore the actual previous version.
* Restore modified content.
* Restore modified assets.
* Restore the previous resume if it was replaced.
* Verify the restored version.

---

## PROJECT IMAGE RULE

Resume information and project screenshots are separate sources.
The resume can provide:
* Project name
* Description
* Technologies
* Contribution

The portfolio owner provides:
* Project screenshot/PNG

If a new project appears in a resume but no screenshot is provided,
ask the portfolio owner to attach the image.

Do not generate fake project screenshots.

---

## MANUAL CONTENT PROTECTION
Not all portfolio content necessarily comes from the resume.
Some content may be manually customized.
Therefore distinguish between:

| Content Type          | Update Behaviour                   |
| --------------------- | ---------------------------------- |
| Resume-derived        | Eligible for synchronization       |
| Manually customized   | Preserve unless approved           |
| Project images        | Preserve unless replaced           |
| Design/CSS            | Preserve unless explicitly changed |
| Website functionality | Preserve unless required           |

A new resume must not automatically delete manually maintained
portfolio content.
